LUNAS

An AI-assisted urban infrastructure maintenance and monitoring system designed to make incident reporting, assignment, repair, and verification faster and more accountable in Dagupan City.

The problem

Urban hazards such as potholes, damaged roads, leaks, and drainage issues can suffer from delayed reporting, fragmented coordination, and limited visibility after submission.

The solution

LUNAS connects citizens, repair personnel, and government officials in one Report → Validation → Assignment → Repair → Verification → Closure workflow.

My contribution

  • Analyzed user roles and translated operational requirements into interface flows.
  • Designed and implemented static Flutter screens with connected navigation.
  • Implemented Google Maps location selection in the report-creation flow.
  • Contributed the UI/UX direction for citizen and operational experiences.

Core features

  • Photo and GPS-assisted incident reporting
  • AI hazard analysis and privacy masking
  • Role-based work orders and status tracking
  • Automated SLA monitoring and escalation
  • Before-and-after repair verification
  • Audit logs and secure records

Interface highlights

These summaries represent the implemented product flows. Full source access remains controlled because LUNAS is a team academic project.

Citizen reporting

Capture evidence, confirm the incident category, and select an exact map location.

Work order tracking

Assigned teams receive incident details, update repair progress, and submit evidence.

Command center

Officials validate reports, monitor SLA deadlines, and review completed repairs.

Challenge and response

A report must contain useful location data without making the flow difficult for citizens. I integrated a reusable map picker into report creation so users can confirm a location visually while retaining coordinate and address fallbacks.

What I learned

LUNAS strengthened my experience in systems analysis, role-based design, Flutter navigation, location services, and translating complex government workflows into understandable interfaces.
